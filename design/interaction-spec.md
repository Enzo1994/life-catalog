# V1.1 · 页面与交互规范草案

此文档明确视觉稿之外的产品行为；待视觉方向选择后细化尺寸、组件与原型。

## 全局规则

- 以 390×844pt 为初始设计基准，兼容更窄屏幕、安全区和动态字体；控件最小触控范围 44×44pt。
- 正文 16–17pt，辅助文字 13–14pt；概念稿中的微小编号不用于关键信息。正文对比度至少 4.5:1。
- 导航栏提供返回与清晰标题；图标需有辅助功能标签。不得仅靠颜色表达选中、失败或进度。
- 底部四入口：图鉴架、拍摄、发现、我的。拍摄作为创建动作打开全屏流程，结束回到来源页。发现二期上线，一期原型标注“稍后开放”，不展示虚假信息流。
- 默认私有；不显示价格、资产总额、库存、估值、连续打卡、排行榜。
- iCloud 状态与云端生成状态分开；生成服务不等于公开内容平台。高级功能一期须验证，不等于强制开通订阅才能保存。

## 01 图鉴架

导航标题“人生图鉴”，搜索入口，所有系列封面共享书架外框。用户自由创建系列，不预置主题模板。演示中的旅行、旧物等系列仅为已有数据示例。

首次打开：一册空白的“随手收藏”；主按钮“拍下第一件”。说明“先拍下来，故事可以以后慢慢写”。无引导填写偏好、注册或付费墙。

已有内容：两列册封面、册名、已收录数量；每册预览 1–3 个物品。新建系列入口固定可发现，很多系列时不依赖滚到底。回顾入口只在有符合日期的内容时出现；没有历史物品时不展示虚构“一年前”。

搜索覆盖物品名、故事、标签和系列；提供系列、来源与标签筛选。搜索无结果时提供清空筛选，不把结果复制成新物品。

## 02 新建系列

底部表单：系列名；自由模式（默认）/ 集齐模式；选择容器风格；物品风格可稍后设置。未输入系列名时明确提示。

自由模式：只显示“已收录 N 件”。集齐模式才显示总数输入、已收录 N / 总数、进度和灰色空位；总数为正整数，不得小于已收录数。未知物品使用中性空位，只有已知目标时才使用对应剪影，避免暗示系统知道未收录物品。

预览优先使用用户已有物品；用户无物品时明确标注“示例物品”。免费容器本地即时预览，不因浏览风格扣额度。

## 03 系列详情

顶部返回、册名、数量、分享、更多。网格 / 时间线切换只是排列视角，不创建副本。风格设置放在更多菜单与可识别的风格入口。

自由模式网格没有缺失空位或进度。集齐模式在标题下显示数字和进度，并在网格末尾展示剩余空位；满额后有轻量文字反馈，不强制庆祝或制造收集压力。

空系列：“这本图鉴，等你放进第一件。”按钮“拍照收录”。删除系列需提供将物品移至“随手收藏”的明确操作，不默默删除原物。

## 04 拍摄 → 抠图确认

入口选择“拍照”或“从相册导入”；权限在触发时请求，拒绝相机权限时仍可选相册。

拍摄页：实时主体轮廓、简短拍摄建议、相册入口、快门。检测到手时显示“手指入镜了，试试换个角度”。不要把未实现的检测效果当成已完成能力。

确认页：居中主体、棋盘透明底（仅编辑器），可切换浅/深底检查边缘。工具依次为点选保留、点选排除、一键去手、画笔；提供撤销、重做和重置。杯碟、底座等候选由用户确认。

主操作“确认主体”；次操作“重新拍摄”。复杂物体失败提示“透明或反光的部分不太容易识别，试试换个背景”。保留“使用原图继续”，不要把识别失败变成死路。被手遮住的部分一期引导重拍，不承诺自动还原。

退出时保留本地草稿并说明可恢复。云端复杂抠图如需上传，也应独立告知上传用途。

## 05 选系列 → 选风格 → 保存

系列默认为“随手收藏”，可点选已有系列或即时新建。风格默认沿用系列；用户无需每次重选。收录过程中如需更换系列统一风格，清晰标注影响整册，避免单件操作意外改整册。

风格分两层：容器（免费、本地）与物品画风（高级、消耗额度）。提供保真度、用量、预计消耗；黏土、卡通、水彩以真实测试结果确定保真等级，不能先承诺高保真。

首次上传生成前说明：“将上传这件物品的图片，用于生成风格图。图鉴默认私有。”提供明确同意动作和“暂不生成”。费用在开始前明确；无同意则不提交云端。

包装文字较多时提示推荐保真度较高的已验证风格；高级功能可选“稍后再试”。原图/抠图可先保存，生成异步进行，不让用户等待模型才完成收录。

最后一屏默认只展示名称与“一句话故事”，均为选填；折叠“再记一点”包含喜欢程度、来源、轻标签。拍照、所属系列、自动收录日期足以保存。名称未填时以“未命名物品”显示，不用强制名称校验阻断。

主按钮“收进图鉴”。成功后：“已经收进「随手收藏」”，提供“再拍一件”和“看看它”。不弹连续打卡或升级付费墙。草稿在成功持久化后再清除。

## 06 生成状态

| 状态 | 用户看到 | 可做的事 |
| --- | --- | --- |
| 排队 / 生成中 | 使用当前抠图作为预览，文字“风格图正在制作” | 继续浏览、查看任务 |
| 离线 | “已保存在本机，联网后可继续生成” | 保留本地版本、稍后发起 |
| 额度不足 | 当前余额、此次消耗，不遮挡已存内容 | 使用原图、查看额度方案 |
| 自动检查未通过 | “细节还不够好，正在重新制作” | 继续使用原图；自动仅重试一次 |
| 仍未通过 | “这次没能保留好物品细节，已保留原图” | 查看原图、稍后重试 |
| 成功 | 风格图可切换，有完成提示 | 查看结果、分享 |

不显示未经测量的百分比或剩余秒数。失败是否扣额度必须与后端政策一致，实施前确定；概念设计不承诺退款。检查透明通道、轮廓、颜色、OCR 的技术阈值另行实验，不能把 OCR 通过等同于全部细节无损。

切换到已缓存的同物品同风格不重复生成；切换整册风格时先列出需要新生成的件数与额度，再开始，绝不自动批量扣费。

## 07 物品详情

主体是视觉中心，下方提供原图 / 抠图 / 风格图切换，清楚标注当前状态；没有风格图时点击进入选择流程，不显示假的结果。

信息顺序：名称、所属系列、收录日期、故事、来源与标签、编辑入口。真实日期与收录日期分开，前者允许只到年或年月，不补造日。无故事时用“写下它的故事”邀请补充，不展示“暂无数据”。

原始素材永久保留；容器效果不烧进原图。二期“后续”、关联人物、长文与多图作为后续设计范围，不在一期页面中做可点击假入口。

## 08 时间线与回顾

总时间线从图鉴架入口进入，每册内也有时间线。按年/月分组；支持精确与模糊真实日期，未填写真实日期时用收录日期，并标注日期含义。视角切换不重复计数。

“一年前的今天”只匹配具备月日的有效日期；仅年份或年月不能伪装成当天回忆。点击回顾打开物品与原故事，可分享回顾卡；一期不要求填写新故事。

## 09 分享

单件卡片与系列海报两种；海报先展示预览，再调用系统分享。提供是否展示故事、日期的开关；不默认公开地点、人物、标签等隐私字段。选择原图或已生成风格版本，不等待新生成即可分享。

导出时本地渲染容器、字体和投影，保持与浏览一致。无任何点赞或公开浏览数。长图属于后续输出能力，一期优先单卡与系列海报。水印权益须与后端方案一致。

## 10 我的

统计只展示系列和物品等温和总量，不做资产估值或排行榜。设置分为默认风格、生成额度、iCloud 同步、导出备份、订阅、隐私。清楚区分本机保存、同步中、同步失败；用户可重试，不用一个笼统“已同步”掩盖任务失败。

一期无自有公开账号体系，不展示虚假的登录和关注关系。订阅/买断尚待商业方案确定，当前不虚构价格和额度。
