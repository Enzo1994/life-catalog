# 原型素材

工具：内置 image_gen。项目文件：public/assets/objects.png。尺寸：1536×1024，RGBA，实际存在透明通道。

素材角色：六件虚构演示物品的独立透明摄影，3列×2行排列；页面用 CSS 精灵定位取用，分享输出用 Canvas 对相应单元取样。实体册、书架、纸张、边框和文字均由代码渲染，未用整张 UI 截图当作应用。

生成提示词：

Create an asset sprite sheet for a sophisticated personal scrapbook catalog app. Exactly SIX photorealistic isolated real everyday objects arranged in a strict 3-column by 2-row equal-cell grid on a fully TRANSPARENT background. Landscape 1536x1024. Each cell is 512x512. All objects centered in its cell, comfortably inside cell with 65px blank transparent padding, no overlapping across cells, consistent object scale around 330px. Row 1 column 1: beautiful blue floral Japanese ceramic mug with handle facing right, slightly aged glaze. Row 1 column 2: one vintage tan Japanese train ticket with small authentic-looking black printed marks. Row 1 column 3: vintage silver and black 35mm film camera, three quarter front view, no readable brand. Row 2 column 1: elegant cream peach scallop seashell. Row 2 column 2: small Mount Fuji blue-white embroidered fabric souvenir keychain with brass ring. Row 2 column 3: one photographic postcard of old Kyoto street in autumn, slightly turned 5 degrees. Photography, realistic material detail, gentle soft studio lighting, crisp edge alpha. No backgrounds, no shadows, no table surfaces, no framing, no labels or titles or extra objects, no UI. These are standalone app assets, not a screen mockup.
