# 人生图鉴 · V1.1 UI 设计探索

日期：2026-10-24。平台：iOS 优先。产品名称暂用。状态：用户已选择 A 白底版，已完成浏览器交互原型；Android 离线抠图测试版和 iOS Apple Vision 桥接已加入，生成服务尚未接入。详见 [原生接入说明](../native/README.md)。

## 可交互版本

仓库根目录运行 `npm run dev`，打开 http://localhost:5173 。入口、运行与边界见[项目说明](../README.md)，实际验证见[QA 记录](qa/README.md)。

## 当前选定方向 · A 白底版

[查看 A · 纸间收藏 · 白底版](concepts/a-paper-white-v2.png)。以用户最新要求覆盖 A 原有底色：页面画布、导航与故事区改用 #FFFFFF；保留彩色册封面、木质书架、拼贴与深色操作。用浅灰边框和轻阴影区分白底上的白色卡片。照片区域保留原始材质色。回顾日期修正为 2025年10月24日。

用户选择及白底要求是当前视觉锁定依据；下方三方向表为历史探索，A 的 #FFF3E7 底色已不再适用。白底版由内置图像生成工具编辑，已目视确认主要页面背景和布局；它仍是概念图。

- [C · 口袋灵感册](concepts/c-pocket.png)：明亮封面、圆润形态、粉色操作，适合强调风格化与分享。

## Refero 研究

研究了三个风格检索方向，读取三份完整风格、两份完整 iOS 页面，以及一条完整照片日记流程。原始研究保存在 research/。

| 参考 | 提取内容 | 使用边界 |
| --- | --- | --- |
| [Craft Docs](https://craft.do) · Refero style 285cc0ca-d47b-495d-9e49-c4326c5cd7ea | 纸张底色、拼贴层次、柔和多层阴影、标题与控件字体分工 | A 的主参考；彩色仅用于册封面、标签；不把网页大字号搬进 iOS |
| [Silencio](https://silencio.es) · Refero style 94a84b2b-7693-4193-8fe5-2061065e2639 | 黑白灰界面、隔离主体、留白、编号 | B 的主参考；物品本身保留真实颜色，UI 不增加彩色装饰 |
| [Playful](https://playful.software) · Refero style 749da11c-6bc7-4c1b-b111-333882d1b828 | 圆润容器、明亮操作色、创作工具气质 | C 的主参考；粉色用于主要动作和选中态，渐变限于封面装饰 |
| [PocketShelf · The Archive](https://refero.design/screens/29be25c1-b1de-4e2a-9298-9c0438c9834e) | 封面优先、清晰分组、适当的册间距 | 仅借用收藏浏览结构，不借用阅读进度语义 |
| [Nooka · Library](https://refero.design/screens/2befe790-d0a9-4740-bef8-8eaa1440ab41) | 私人内容库、图片与短故事并列、全局导航 | 不引入人物头像、公开社交或喜欢数 |
| [one year · Create daily memory with photo](https://refero.design/flows/10993) | 系统选图、预览、保存返回、图片与故事关联 | 收录沿用低摩擦模式，文字可跳过，不采用按天打卡 |

## 视觉锁定候选

| 项目 | A · 纸间收藏 | B · 私人物件馆 | C · 口袋灵感册 |
| --- | --- | --- | --- |
| 主底色 | #FFF3E7 | #FFFFFF | #F6F2EE |
| 主文字 | #030302 | #000000 | #0F172A |
| 主操作 | 深色实心 | 黑白反相 | #FF2E95 |
| 表面 | 白纸、轻多层阴影 | 灰白薄层、细分隔线 | 白卡片、柔和抬升 |
| 文字 | 宋体标题 ≥24pt；苹方控件和正文 | 苹方标题和正文；数字编号等宽 | 苹方中粗标题；常规正文 |
| 圆角候选 | 14 / 24pt | 7 / 胶囊 | 16 / 44 / 胶囊 |
| 媒体 | 实体册、纸张与真实物品 | 原物摄影与抠图 | 原图与风格图对比，彩色封面 |
| 明确避免 | 大面积棕色、过量撕纸、文字可读性下降 | 资产台账、过密编号、低对比小字 | 盲盒游戏、勋章、积分、全屏渐变 |

中文字体是面向 iOS 的本地化映射，不假设 Refero 网页的商业字体可直接商用。上述三套为独立方向，不混合平均；选择后才能形成最终 token 和组件规格。

## 决策记录

| 决策 | 来源 | 原规则/角色 | 原因 |
| --- | --- | --- | --- |
| 首页统一书架，系列封面承载差异 | 用户 V1.1 + PocketShelf | 系列是册，物品是内容 | 避免风格切换导致首页杂乱 |
| 自由系列只出现数量 | 用户 V1.1 | 无总量、无空位 | 降低集齐压力 |
| 原图、抠图、风格图可切换 | 用户 V1.1 | 原图永久保留 | 建立保真信任 |
| 故事置于主体下方 | 用户 V1.1 + Nooka | 情感内容优先于元数据 | 体现生活记录定位 |
| 相册使用系统选择器 | one year 流程 | 用户选择照片后回到编辑 | 降低权限与操作摩擦 |
| 风格化可稍后做 | 用户已拍板为高级功能 | 本地存储不依赖云生成 | 保证拍完即存 |
| 发现页一期标注稍后开放 | 用户 V1.1 的四标签与二期规划 | 不展示未审核公开内容 | 不伪装已上线能力；是否隐藏整个标签待产品确认 |
