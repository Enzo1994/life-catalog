# 白底版交互原型 · 验证记录

日期：2026-10-24。源目标：[A 白底版](../concepts/a-paper-white-v2.png)。实际实现：React DOM + CSS；物品使用独立透明摄影素材。保留纯白画布、彩色纸册、木质搁板、深色主操作与宋体标题，控件使用系统无衬线字体。

## 已运行

- `npm test`：6 项通过。覆盖回顾日期、自由系列无固定上限、集齐容量、总数校验、跨系列搜索、选填字段为空时仍可保存。
- `npm run build`：通过，生成 dist。
- 本地浏览器日志：本轮检查未发现 error/warn。

## 浏览器内手工验证

| 流程 | 结果 |
| --- | --- |
| 首页 → 旅行系列 → 时间线 → 物品故事 | 正常切换，未创建物品副本 |
| 单件分享 → 隐藏日期 → 保存 PNG | 导出流程完成，弹窗关闭 |
| 系列分享 → 保存 PNG | 实际导出 1000×1420 海报，并目视检查无物品或文字重叠 |
| 拍摄 → 示例物品 → 选系列 → 新建集齐系列 | 新系列成功创建并自动选中 |
| 集齐总数设为 2 → 名称与故事均留空 → 保存 | 成功生成一条未命名记录 |
| 刷新浏览器 | 系列与已保存记录仍存在 |
| 集齐系列详情 | 显示 1/2、50% 及一个同排空位 |
| 相册选择项目内示例 PNG | 进入主体确认页；读到的自然尺寸仍为 1536×1024，data URL 保持 image/png |
| 窄屏、基准 iOS、桌面 | 实测 CSS 视口宽约 291、391、1309px，documentWidth 均等于 viewport，没有横向溢出；临时视口覆盖已恢复 |

当前浏览器保留一册手工测试创建的“周末的两件小事”及一件未命名示例物品，可直接体验集齐模式。全新浏览器默认仍为原来的四册、六件虚构示例数据。

## 视觉修正

- 调整小屏辅助文字字号与对比度，关键控件保留触控范围。
- 压缩首页册封面高度和顶部节奏，使两层书架在基准手机视口内可见；内容多时正常纵向滚动。
- 集齐空位改为与已收录物品共用同一网格，不单独堆在网格下方。
- 长物品名称在导出的单件卡片中自动折行。
- 照片导入由缩放 JPEG 改为直接保存原始 data URL，不静默损失像素或透明度；单张 3 MB 的原型限制在入口明示。

## 未验证与边界

这次完成的是可交互浏览器原型，不是原生 iOS 工程。没有进行真机相机权限、VoiceOver、iCloud、多设备同步、模型生成质量、OCR 或生产级长时间存储测试。JSON 备份仅可导出。相册原文件导入已验证，摄像头入口依赖系统文件选择器，未声称实现实时相机或实时抠图。
